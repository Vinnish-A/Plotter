# Mutation Rules

Mutations alter visual grammar while preserving data claims.

Allowed:

- add focus halo or callout
- add local detail panel when optional data supports it
- convert simple annotation to a track when categories are meaningful
- add marginal or summary panel when it explains the main body
- recombine compatible layouts from reviewed asset cards

Blocked:

- turning compatibility columns into true network roles without evidence
- adding unsupported uncertainty intervals
- using decorative tracks that steal main-panel attention
- changing the primary claim to fit a prettier layout
- writing generated outputs under Bastard
