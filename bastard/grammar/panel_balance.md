# Panel Balance

Panel area should match visual work.

Rules:

- Primary panel should usually have the largest area.
- A support panel may be larger only if it has high information density and independent meaning.
- Low-information support should be narrow, strip-like, inset-like, or visually quiet.
- Decorative elements must never dominate data marks.
- Empty space is acceptable only for labels, callouts, or narrative clarity.
