# Retinue Visual Checks

Retinue validates generated outputs after rendering. File existence and nonblank pixels are not
enough for Agent scenario tests.

Additional Agent self-review principles:

- Main/subordinate hierarchy must be visually clear.
- A support or decorative panel may be larger than the main panel only when it carries high
  information density and independent interpretive value.
- A low-information support panel must be narrow, strip-like, inset-like, or otherwise visually
  subordinate.
- Decorative elements must not dominate data marks.
- Area allocation should roughly match data complexity and mark density.
- Strongest chroma/contrast should serve scientific focus, not decoration.
- Annotation tracks are auxiliary; they must not steal the main coordinate semantics.
- Empty space is allowed only when it improves label placement or narrative clarity.
