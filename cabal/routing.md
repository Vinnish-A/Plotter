# Routing

Route by task type:

- Template Mode: `Cabal -> Vault -> Retinue`
- Graft Mode: `Graft -> Vault`
- Bastard Mode: `Cabal -> Vault -> Bastard -> Cabal -> Retinue -> Vault`

Use Template Mode for direct reuse, Graft Mode for foreign code ingestion, and Bastard Mode for focused recombination or controlled unfamiliarity.
